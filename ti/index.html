Pipeline em Python que classifica e organiza automaticamente os e-mails de duas contas Gmail, uma pessoal e uma institucional da USP, usando a API do Claude (um modelo de linguagem) com acesso por IMAP e OAuth2. O sistema gera resumos diários e semanais com os prazos em ordem cronológica e as ações sugeridas, e os entrega pelo Telegram, onde um bot também aceita comandos manuais.

A Python pipeline that automatically classifies and organizes the emails of two Gmail accounts, one personal and one institutional at USP, using the Claude API (a language model) with IMAP and OAuth2 access. The system produces daily and weekly summaries with deadlines in chronological order and suggested actions, and delivers them through Telegram, where a bot also accepts manual commands.

Pipeline Python qui classe et organise automatiquement les e-mails de deux comptes Gmail, l’un personnel et l’autre institutionnel de l’USP, avec l’API Claude (un modèle de langage) et un accès par IMAP et OAuth2. Le système produit des synthèses quotidiennes et hebdomadaires avec les échéances dans l’ordre chronologique et les actions suggérées, et les livre par Telegram, où un bot accepte aussi des commandes manuelles.

A arquitetura é híbrida: a formatação determinística fica no Python e a IA entra só na análise estratégica, o que reduz o consumo de tokens. O sistema está sendo migrado para um servidor virtual (VPS) na Oracle Cloud, com execução agendada por cron, deploy por Git e acesso por SSH, para funcionar sem depender do meu computador.

The architecture is hybrid: deterministic formatting stays in Python and the AI is used only for strategic analysis, which reduces token consumption. The system is being migrated to a virtual private server (VPS) on Oracle Cloud, with scheduled execution through cron, deployment through Git and SSH access, so it runs without depending on my own computer.

L’architecture est hybride : la mise en forme déterministe reste en Python et l’IA n’intervient que pour l’analyse stratégique, ce qui réduit la consommation de tokens. Le système est en cours de migration vers un serveur privé virtuel (VPS) sur Oracle Cloud, avec exécution planifiée par cron, déploiement par Git et accès par SSH, afin de fonctionner sans dépendre de mon ordinateur.
