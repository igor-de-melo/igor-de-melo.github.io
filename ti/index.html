ProblemaProblemProblème
Acompanhar duas contas Gmail, uma pessoal e uma institucional da USP, sem perder prazos nem ações pendentes.Keep track of two Gmail accounts, one personal and one institutional at USP, without missing deadlines or pending actions.Suivre deux comptes Gmail, l’un personnel et l’autre institutionnel de l’USP, sans manquer d’échéances ni d’actions en attente.
AbordagemApproachApproche
Pipeline em Python que classifica e organiza os e-mails com a API do Claude (um modelo de linguagem), com acesso por IMAP e OAuth2. A arquitetura é híbrida: a formatação determinística fica no Python e a IA entra só na análise estratégica, o que reduz o consumo de tokens.A Python pipeline classifies and organizes the emails with the Claude API (a language model), with IMAP and OAuth2 access. The architecture is hybrid: deterministic formatting stays in Python and the AI is used only for strategic analysis, which reduces token consumption.Un pipeline Python classe et organise les e-mails avec l’API Claude (un modèle de langage), avec un accès par IMAP et OAuth2. L’architecture est hybride : la mise en forme déterministe reste en Python et l’IA n’intervient que pour l’analyse stratégique, ce qui réduit la consommation de tokens.
ResultadoResultRésultat
Resumos diários e semanais com os prazos em ordem cronológica e as ações sugeridas, entregues pelo Telegram, onde um bot também aceita comandos manuais. A migração para um servidor virtual (VPS) na Oracle Cloud, com cron, deploy por Git e acesso por SSH, faz o sistema rodar sem depender do meu computador.Daily and weekly summaries with deadlines in chronological order and suggested actions, delivered through Telegram, where a bot also accepts manual commands. The migration to a virtual private server (VPS) on Oracle Cloud, with cron, Git deployment and SSH access, lets the system run without depending on my computer.Des synthèses quotidiennes et hebdomadaires avec les échéances dans l’ordre chronologique et les actions suggérées, livrées par Telegram, où un bot accepte aussi des commandes manuelles. La migration vers un serveur privé virtuel (VPS) sur Oracle Cloud, avec cron, déploiement par Git et accès SSH, permet au système de fonctionner sans dépendre de mon ordinateur.
