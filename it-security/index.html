Como funcionaHow it worksComment ça marche
  1. A rede tem 64 máquinas; cada uma se liga às três mais próximas e às que estão num raio fixo, com grau médio k̄ ≈ 3,8.
  2. Modelo SIR discreto: a cada passo, cada máquina infectada contamina cada vizinha vulnerável com probabilidade β; depois, cada infectada é isolada com probabilidade γ.
  3. A chance de uma infectada contaminar uma vizinha antes de ser isolada é T = β / [1 − (1 − β)(1 − γ)].
  4. O número básico de reprodução é R0 ≈ k̄·T. Acima de 1, o surto tende a crescer; abaixo de 1, a se extinguir. Em redes reais, a estrutura das ligações também pesa.
  5. Na prática de segurança, γ representa detecção e resposta (monitoramento, isolamento de máquinas) e β, a superfície de ataque, que se reduz com correções, segmentação e menor privilégio.
  1. The network has 64 machines; each links to its three nearest neighbors and to those within a fixed radius, with mean degree k̄ ≈ 3.8.
  2. Discrete SIR model: at each step, every infected machine compromises each susceptible neighbor with probability β; then each infected machine is isolated with probability γ.
  3. The chance that an infected machine compromises a neighbor before being isolated is T = β / [1 − (1 − β)(1 − γ)].
  4. The basic reproduction number is R0 ≈ k̄·T. Above 1 the outbreak tends to grow; below 1, to die out. In real networks, the link structure also matters.
  5. In security practice, γ stands for detection and response (monitoring, host isolation) and β for the attack surface (patching, segmentation, least privilege).
  1. Le réseau compte 64 machines ; chacune est reliée à ses trois plus proches voisines et à celles situées dans un rayon fixe, avec un degré moyen k̄ ≈ 3,8.
  2. Modèle SIR discret : à chaque pas, chaque machine infectée contamine chaque voisine vulnérable avec une probabilité β ; puis chaque machine infectée est isolée avec une probabilité γ.
  3. La probabilité qu’une machine infectée contamine une voisine avant d’être isolée est T = β / [1 − (1 − β)(1 − γ)].
  4. Le nombre de reproduction de base est R0 ≈ k̄·T. Au-dessus de 1, l’épidémie tend à croître ; en dessous, à s’éteindre. Dans les réseaux réels, la structure des liens compte aussi.
  5. En sécurité, concrètement, γ représente la détection et la réponse (supervision, isolement des machines) et β, la surface d’attaque (correctifs, segmentation, moindre privilège).
