## Projects

### Intelligent email triage

Personal project · In development

**Problem:** Keep track of two Gmail accounts, one personal and one institutional at USP, without missing deadlines or action items.

**Approach:** A Python pipeline classifies and organizes the emails using the Claude API (a large language model), accessing mailboxes via IMAP with OAuth2. The architecture is hybrid: deterministic formatting stays in Python and the AI is used only for strategic analysis, which reduces token consumption.

**Result:** Daily and weekly summaries with deadlines in chronological order and suggested actions, delivered through Telegram, where a bot also accepts manual commands. The system runs locally and on a VPS (Oracle Cloud), scheduled with cron, and processes any number of emails, with no fixed limit (it depends on the inbox). Estimate: 1 to 3 minutes saved per email. Planned: migration to a 24-hour local server on a Raspberry Pi.

Stack: Python, Claude API, IMAP, OAuth2, Telegram Bot API, Linux, cron, Git, SSH, Oracle Cloud (VPS)

### Job search and ranking engine

Personal project · In development

**Problem:** Find and screen internship and job listings spread across many sources.

**Approach:** A pipeline scans a predefined list of sources, removes duplicates and gives each listing a fit score from 0 to 10 based on defined criteria: type of role, location and eligibility requirements.

**Result:** A tracking spreadsheet with a summary of each listing’s requirements and duties. No application is sent without my review and confirmation: the automation does the prep work; I make the decisions.

Stack: Claude, Claude Code, Browser automation
